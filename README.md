# 工作日志

我在做搜索质量评测，用模型判断搜索结果对用户有多大帮助，也用人工相关性标注比较两个版本的搜索排序。这里也收录我在评测、资料采集和调研中使用的 skills。

## 项目导航

| 入口 | 适合什么任务 | 可以看到什么 |
| --- | --- | --- |
| [搜索结果质量评测](projects/search-quality/) | 给一批搜索结果打分，检查评分证据，查看模型与人工判断的分歧 | 输入清洗、模型评分、排序指标、本地工作台和离线示例 |
| [离线排序评测工具](projects/search-eval/) | 已有人工相关性标注，需要比较两版排序 | Precision、Recall、F1、MAP、NDCG，以及逐查询差异和 HTML 报告 |
| [Skills 目录](skills/) | 单独使用一套评分规则，或者为调研收集材料 | 结果块需求满足度、标准需求满足度、页面质量、网页正文抓取和 AI 资讯 |

两个项目均可从各自目录独立运行。每个 skill 的入口是对应文件夹内的 `SKILL.md`。
