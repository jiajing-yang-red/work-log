方案 legacy_five_v1，规则版本 1.1：依据 evaluation/context-search-quality-evaluation/SKILL.md 及旧目录的 API-only 校准、评分边界说明重建。不是当时最终 GPT 分片复核 prompt 的完整复现。
本任务评估 answerability、authoritative、freshness、noise；duplicate 由独立列表任务判断。

可回答性 answerability，必须先核对所问对象、事件/事实和属性，再检查明确的时间、site:、指定 URL、filetype:、版本、型号等必要条件：
3：同一对象/事件/事实，结果直接、清楚、完整地支持正确答案，没有影响答案选择的竞争信息。
2：同一对象/事件/事实，完整正确答案已经出现在本条结果中，但混有竞争答案、不同时间段或实质干扰，需要消歧。reason 必须说明正确答案在哪里、需要排除什么竞争信息。2 绝不是部分完成。
1：同一对象/事件/事实，但所问答案缺失、不完整，或关键条件/当前有效性未获证实。实质需求只满足一部分时为 1，不能因相关、官方或内容很长升为 2/3。
0：不同对象/事件/事实/所问属性，仅关键词或主题重合、假相关、空白、明确被阻挡/删除、无实质内容或对本 query 不可用。错品牌、型号、股票代码、比赛或实体即使可能误导也为 0，不是 -1。
-1：确实回答同一所问事实，但答案已确认错误；或相关内容超出实际时间要求，且会误导当前回答。必须给实际错误/过期的证据和简短原因。不同事件的旧内容仍为 0；缺证不等于错误，不能仅凭年代旧给 -1。
在 0 与 -1 之间不能确认时选 0，不猜测错误；已经确认同一事实但答案缺失、不完整或有效性未证实的，按 1 分规则处理。
2/3 必须覆盖全部实质需求，全部明确必要条件均已确认通过，并满足实际时间要求。不能拿参考答案或其他结果补齐本条缺口。
官方文档直接指出所问参数、字段、方法或行为且已满足实际需求时，可以给 3；query 未要求完整教程或代码示例时，不因缺这些材料降分。
例如：要求比较 A/B/C 而只比较 A/B，给 1；要求 c05 PDF 而只有相关 c048 文档，不能给 2/3，若仍是相关线索可给 1；历史官方邮箱不能证明当前仍有效时给 1，除非已有证据确认它错误/过期并会误导才给 -1。
宽泛新闻需求可以由多个符合范围的事件满足，不能硬要求唯一事件；多事件关键词串也不能机械把每个词变成必答项，或把单一事件当成已完整回答组合调查需求。依据 query 真实意图判断，并说明边界。

权威性 authoritative 与 authority_tier：
S1=approved_authority_domains 中已维护的人工认可来源；S2=可确认的官方/第一方来源；S3=高流量或成熟专业媒体；S4=UGC/独立作者；S5=其他来源。
S1/S2 才为 true，S3/S4/S5 为 false。没有认可名单不能发明 S1；高流量或域名看起来专业不证明官方身份。
没有可见证据确认 S1/S2 时按可见来源类型选 S3/S4/S5，身份信息不足归 S5、false，并在 reason 说明未证实官方/认可身份；不得把缺证写成已证实不可信。

时效性 freshness：
评价结果是否满足 query 的实际时间要求，不能只判断这一类内容是否通常时效敏感。F1 分钟级≤30分钟；F2 >30分钟≤6小时；F3 >6小时≤24小时；F4 >24小时≤7天；F5 长期稳定（至少7天，通常30–90天复核）。
F1–F4 必须 freshness_applicable=true，并对每一条结果给 true/false，不排除不相关结果。只有 query 实际没有时间要求才可 not_applicable/null；F5 也需检查显式年份、版本或当前有效性要求。
显式历史年份、事件和截止时间以 query 为准；相对时间以 evaluation_as_of 为准。提供独立 Golden Answer 时使用其核验截止时间。不让截止之后的信息倒灌为答案。
依据内容实际发布时间/更新时间及事实有效性，核对同一事件和所需时间窗口；抓取/索引时间不等于发布时间，published_at 不自动证明有效。正文、标题或 URL 中的明确事件日期冲突必须解释。
没有日期不自动代表过期；若内容能确认满足目标事件/时间，仍可 true。若决定性时间证据不足，不能确认满足则 false，并说明缺少什么证据，不声称已证实过期。缺少评估时点时仍判断可确认的不相关/无用结果，不把所有维度一起跳过。
有时间要求时，不相关、错误、不可用或会误导的过期结果为 false；相关但无法证明当前有效的线索可为 answerability=1、freshness=false；同一事实已确认过期并会误导才为 answerability=-1。

噪声 noise：
不同事件/事实、不相关、假相关、错误、误导性过期内容、无实质信息、明确不可访问/401 或已删除等，均为 true。answerability=0/-1 必须 noise=true；3 分的直接、完整、清楚答案不能同时是 noise=true。
内容相关但答案不全不自动是噪声。重复也不自动是噪声；只有同时满足上述噪声定义才两项都为 true。

辅助检查：temporal_fit 表示是否满足真实时间需求；reliability 表示用来支撑所问答案的证据是否充分可靠。它们的 unknown 只记录证据缺口，不是评分状态；缺口落实为保守分档和理由。
2 分中混有的竞争信息须可消歧，支撑正确答案的证据本身仍应可靠。2/3 不得与 temporal_fit=fails、reliability=contradicted/insufficient/unknown 同时出现；时效适用时，2/3 必须 freshness=true、temporal_fit=meets。
