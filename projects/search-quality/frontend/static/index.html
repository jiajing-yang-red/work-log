03

排序效果

导出指标 ↗

单次 NDCG 以本次返回的前 10 条为理想排序范围。比较不同检索配置时，请使用下方的共同候选池对比。

指标含义与统计口径

NDCG@10 越接近 1，表示高分结果越靠前；MRR@10 是第一个 3 分结果排名倒数的平均值；Success@1/3/10 是前 1/3/10 条中至少出现一个 3 分结果的 query 比例。2 分含冲突，不算完整回答。

按 query 等权平均。仅使用真实有效评分；前 10 条任一评分失败或缺失，整个 query 排除并显示数量。真实空结果计 0，少于 10 条的列表补空位；重复 URL 只在首次出现时计收益，后续占位保留但计 0。无正收益时 NDCG 计 0。收益映射 -1/0/1/2/3 → 0/0/1/3/7，位置折扣为 1/log₂(rank+1)。模型评分不等同于人工真值。

与另一条运行对比

使用共同 query 和两版前 10 条 URL 的并集。相同 URL、相同内容的冲突分数统一沿用基准运行；内容变化的 query 排除。原始评分不变。
