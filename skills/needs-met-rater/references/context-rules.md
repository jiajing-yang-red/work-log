# 影响五档的上下文规则与例外

以下规则依据可见块与明确提供的上下文执行。LP 指落地页；涉及完整页面状态的规则用于区分评价对象，不查看或推测未提供的正文。

按问题阅读对应主题：页面质量、特殊标记、多意图、具体程度、时效、拼写与姓名、URL 查询、商品、地点距离、英语结果、词典百科。

## 页面质量与需求满足

- NM 依赖 query 与 result；PQ 不依赖 query。本技能只评需求满足，不输出 PQ，也不推断 LP 的完整质量。
- 无用的结果始终 FailsM，即使 LP 质量高。权威网站没有所需答案也可能无用。
- 不可信，或存在过时、不准确等不良特征的页面不适合 HM。对本模式，只把有依据的可见问题计入，不从缺少作者简介等推断整页质量低。
- 胡言乱语、诈骗等极低质量问题使结果不再有帮助甚至有害，通常 FailsM。
- **明确网站意图的例外：** 明确的网站意图下，目标网站应 FullyM；用户可以搜索任何网站。该例外属于普通 NM，不得用来推断正文，也不使任何带该域名的摘要自动 FullyM。Block Content 仍只评可见块是否满足所求。

## 标记与 Needs Met

### 标记和评分是不同判断

标记依据结果本身，不因 query 是否请求而取消；NM 仍依赖 query。部分标记需要 LP 才能确认，本四字段输出不生成未经观察的 LP 标记，不把未知当成否。标记本身不构成第六档。

### 色情

- Porn 标记适用于块内或 LP 的色情图片、文字、链接、弹窗或显著广告，不取决于 query；判断还需考虑当地文化。
- 明确非色情意图：色情结果无用，应 FailsM。普通的人群、关系、身体或穿着查询不能擅自解释为色情请求；如 girls、wives、gay people、people kissing 等。
- 同时存在色情和非色情解释时，按**非色情解释主导**评分，即使一部分或很多用户可能另有所求。
- 明确色情意图时，仍按结果与具体需求的适配及帮助评分，不能全部给 MM/HM；恶意软件下载等糟糕体验应低档。
- 明确寻找某色情网站的目标页可 FullyM，同时有 Porn 标记；四字段不能照搬其 LP 评价。

### 外语

- 不对以下 LP 语言使用 Foreign Language 标记：任务语言、任务地区相当比例人口常用的语言、英语。
- 其他外语页面根据当地用户判断；即使评分者懂、用户明确想要该页面，仍按标记规则处理。标记依据 LP，不依据块外观；混合语言／无文字难以判断时，有疑问则不标。
- 通常，被标外语的页面因多数当地用户无法理解而 FailsM；但明确期待外语页面时不应自动 FailsM，特定网站目标可以 FullyM。
- 用户寻找外语歌曲、乐队、电影、赛事等时，相关视频可能可欣赏而有帮助；如果只是用用户不懂的语言谈论它们，则可能 FailsM。
- 当前技能不评 PQ，也不能推测 LP 语言。**英文不打外语标记，不等于英文必然有用**，还须结合“非英语地区的英语结果”判断。

### 未加载

- Did Not Load 依据 LP：完全空白，或只有服务器／应用错误且无其他主内容、导航、辅助内容或广告。真正未加载应 FailsM。
- 恶意软件警告、已删除／到期内容、需要订阅才可查看，不按此标记处理；并不表示这些情况必然有用。
- 部分加载或自定义错误页仍按实际帮助评分，不能见到 404 字样就机械 FailsM。
- 当前未打开 LP，不能声明它加载成功或失败；空摘要、字段 null、抓取失败均不等于 LP Did Not Load，也不能据此给块 FailsM。

### 其他标记

- Upsetting-Offensive：按当地典型用户判断可能令人不安或冒犯的内容；考虑互联网用户的年龄、性别、种族、宗教、政治观点等差异。
- Not-for-Everyone：可能让部分当地用户不适、不宜在公共场所／工作／学校查看的内容。
- 本节不为标记单独规定固定档位；结合意图、FailsM 的内容限制和实际帮助判断。

## 多种有帮助的结果

- 不同合理解释、同一解释下的不同意图、甚至同一用户同时拥有的多个意图，都可以对应 HM。
- 格式、真实经验／观点、内容深度（很短摘要到长纪录片）、网站类型都可以多样；不要把某一种形式当成唯一高档。
- 意见与体验、主观问题、浏览探索、没有唯一正确答案的查询尤其受益于多样性。
- 准确理解查询解释；当前离线四字段无法完成外部研究，不编造已研究的结论，对实质歧义记录不确定性。
- **网站与到店双意图：** Website 可能为在线查信息、购物、预约或客服等；Visit-in-Person 为到店。二者都很强时，只满足一种不能 FullyM，但可以 HM。

## 查询与结果的具体程度

- 查询越具体，通常越容易理解需求；评分仍以帮助为依据，不以“具体程度恰好一致”为依据。
- 宽泛类别（咖啡馆、酒店、书、巴黎景点等）中的热门、显著代表例子可以非常有帮助；不是所有具体结果都低档。
- 过于狭窄的对象可能只服务很不常见的意图，或几乎没有帮助；例如宽泛酒店查询中缺乏合理上下文的一家偏远小酒店。
- 判断当地热门／显著对象需有依据，不将无法确认的热度或知名度当作事实。

## 时效

- 突发新闻／灾害信息常需立即可用的最新内容。
- 周期事件（选举、体育、电视节目、会议、税表等）通常指当前或最近／即将发生的一次。
- 当前信息（人口、债务、价格、机票、下个假日等）通常需最新值。
- 产品查询通常指最新型号／版本，除非查询限定其他时间或型号。
- 需要新内容时，只有当前、近期或更新的信息才适合高档；旧事件、旧型号、旧价格等可低档，完全失效时 FailsM。
- 同一名人或政治人物查询可同时有近期新闻和长期背景意图，不能把历史信息全部判无用；已知的历史事实未必需要新页面。
- 档案页面可能 PQ 高但对当前 query 的 NM 低；失去维护且内容错误／误导还可能影响 PQ。此处只按可见证据评 NM。
- 创建时间不等于更新时间；显示当天日期不证明内容已更新。
- 按明确的查询发生时点或用户指定的评价时点解释时间，不自动以评分执行日替代查询中的“当时”。缺时点且会改变结论时复核；无日期不是过时证据，也不能仅凭“实时”等文字认定内容最新。

## 错拼、输入错误与姓名

- 明显错拼按实际意图评分，不死守错误拼写。
- 不明显时尊重原写法；姓名不同拼写可能属于不同的人，不能为了匹配结果随意纠正。
- 例如 john stuart 不能自动改成 Jon Stewart；micheal jordan 的合理解释包括真实同名者，著名运动员 Michael Jordan 在该例被视为可能性很低的次要解释。

## URL 查询的非 FullyM 结果

- 合法可用的 URL 查询，不仅有 FullyM／FailsM 两种结果。
- 查该网站的评论、声誉、近期新闻也是合理意图；相应结果可非常有帮助。零售网站的优惠信息也可能对用户有帮助。
- 网站使用量／流量统计通常不是大多数用户所需；不能因包含该域名就认为有用。
- URL 查询的非目标域名不自动 FailsM；仍只计块展示的实际帮助。

## 商品查询

- 明确 reviews 可是 Know，buy 可是 Do，指定商店网址可是 Website；多数商品 query 未明确唯一意图。
- 用户可能享受浏览和视觉探索，需研究评测、规格、品牌型号、价格、外观与可选项，再决定购买。
- 能帮助研究、浏览、决定买什么的结果应有机会获得高档；不要求立即购买，也不假定最终一定在线购买。
- 商品涉及购买决策，要谨慎处理可见的可信度／误导线索；当前不做完整 PQ，不想象未见商品图与购买功能。

## 地点与到店距离

- query 明确指定地点时尊重该地点；有到店意图且未指定地点时，以用户位置附近最有帮助。
- 附近没有统一公里数：加油站、咖啡馆、超市通常应很近；医生、图书馆、特定餐厅、游泳池、步道可更远；特殊专科诊所可能接受更远。
- 位置也可影响非到店事实，例如当地最低工资；但不是每个 query 都受位置影响，不能强行把网站查询改为找公司办公室。
- 当前缺位置时不猜城市／国家。若位置缺口决定解释或距离是否可用，复核或弃权，而非认定结果已经“太远”。

## 非英语地区的英语结果

- 按目标地区用户是否期待、能否使用英文评分，不以评分者会英文代替判断。
- 当地语言 query 通常偏好当地语言；多数用户读不懂、且 query 没请求英文时，英文结果可无用／FailsM。
- 英文专名、英文词或拉丁字母输入不自动意味着希望看英文；需考虑当地官方语言、常用语言、方言、文字和键盘习惯。
- 明确官方国际网站、适合该需求的英文技术命令／公式／规格，或英语为当地常用语言等情形，英文可有帮助。
- 有疑问时，除非 query 明确另有所指，按用户偏好任务语言处理。评分说明所用语言不代表用户所在地区。

## 词典与百科

- 主题相关不等于满足需求。用户很可能问“是什么／什么意思”，且结果确实有帮助时，词典百科才适合高档。
- 对当地用户普遍理解的常用词，找定义往往只是很不可能的次要意图，SM 可合适。
- 同一百科页面对概念、历史等意图可能有帮助，对“附近哪里有 ATM”等地点任务可能 FailsM；不能按页面类型固定分数。
