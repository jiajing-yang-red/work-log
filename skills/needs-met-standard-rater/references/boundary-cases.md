# 定档边界案例

以下按给定情境说明规则。案例网页、品牌或数字来自特定快照；不代表其当前状态。不要靠记住网站名套分，改变了查询、页面、位置、时间或结果形式，须重新判断。

| 情境 | 结论／边界 | 决定性原因 |
|---|---|---|
| amazon 查询，压倒性主导意图为访问 Amazon，正确网站 | FullyM | 存在其他词义不取消明确主导导航。 |
| www.netflix.coom，正确 Netflix 网站 | FullyM | 明显误拼按真实导航意图。 |
| titanic imdb，正确电影的 IMDb 页面 | FullyM | 同时满足特定内容与特定网站。 |
| 正确电话号码以可直接拨打的块清晰呈现，已用商家官网核实 | FullyM | 特定事实完整、清楚、准确、可信。 |
| 简单地理问题，块内显著给出准确答案 | 可 FullyM | 仍须三个条件及事实核验。 |
| 同一简单地理问题，普通网页需点击，答案混在大量资料内，摘要不突出 | HM | 落地页有正确答案不自动使结果完全满足。 |
| 今天当地天气块，完整准确，属于任务生成至评分的显示延迟 | 可 FullyM | 不因评分延迟处罚原本即时的信息；不忽略地点／事实错误。 |
| 指定某加油站，块提供正确门店与到访信息 | FullyM | 特定到访目标可完全满足。 |
| 远处特定地址块提供地图、方向、地标，但部分人还希望照片／简介 | HM+ 至 FullyM | 显式地点优先；根据是否几乎所有人完全满意保留边界。 |
| knitting、一般名人姓名或无主导解释的 ada | 不能 FullyM | 意图宽泛、多样或存在多个常见对象。 |
| sam wen 之类普通人姓名，没有主导人物证据 | 不能 FullyM | 不能因名字少见就假设唯一对象。 |
| trader joes，有到店和官网两种强意图，完整当地门店列表 | HM | 即使涵盖全部当地门店，也未充分满足网站意图。 |
| 同一查询的官网，需用户再寻找门店信息 | HM | 官方身份不消除未直接满足的另一强意图。 |
| MoMA 地点块带官网链接，但网站访问信息仍不如完整网页结果 | HM | 有链接不等于两种意图都完全满意。 |
| nearby coffee shops，优质本地列表但当地选择很多 | HM | 很有用，不保证几乎所有人对这份名单完全满足。 |
| around the world tutorial soccer，清楚演示与解说的视频 | HM | 视频实作可以比长文更适合。 |
| trestle bridge，有帮助的桥梁图片 | HM | 视觉可充分服务合理理解意图。 |
| emily blunt，热门参演电影块 | HM | 作品信息是合理意图，不需覆盖所有人物信息。 |
| invasive species，清楚且有帮助的概述，尚可增加例子 | HM | 不要求每个结果覆盖全部可能子问题。 |
| Avatar 电影评论查询，汇集真实评论并有实质讨论 | HM | 多观点与论坛形式不降分。 |

| 同 URL 的地图块与外观／内容完全不同的网页块 | 不标重复 | URL 相同不代表搜索体验相同。 |

## 操作边界（并非额外的评分等级）

- 只有普通网页的标题、摘要和 URL：应先取落地页；取不到关键证据则 insufficient_evidence，不给一个伪装成标准 NM 的摘要分。
- 服务商返回 404／403，但尚不知用户实际页面状态：不能用 Did Not Load 或 FailsM 代替抓取失败。
- 安全限制或专业知识不足且无法可靠判断：unable_to_assess，不以 MM 表示不确定。
- 任务明确标记无需评分的上下文结果：not_required，不按灰色滑杆当作 FailsM。
