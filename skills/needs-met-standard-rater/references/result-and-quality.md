# 结果范围、证据与页面质量

## 1. 标准 Needs Met 的分流

| 结果类型 | 评价依据与操作 |
|---|---|
| Web Search Result Block | 通常含标题链接、URL 和摘要。点击是使用结果的必要步骤，必须查看实际落地页后评估。摘要没有答案不能据此 FailsM；摘要说有答案也不能当作页面确实有。仍检查非常误导的结果标题造成的体验问题。 |
| SCRB，多数用户不需点击 | 块内信息／功能已经直接服务需求，依据块本身评分。可以为核实事实而查外部来源，但外部内容不算该块向用户提供的内容。 |
| SCRB，一些或很多用户会点击 | 块内内容始终是主要依据，可同时考虑关联落地页；结合评价时两者都须有帮助才能支持高分。解释用户为什么会点击、评价了哪些关联页面，不用“块与网页取最高分”或平均分。 |

SCRB 可以是即时答案、天气、计算器、地图／地点、图片、视频、新闻集合等。任务里的截图可能无法完整操作，应假定**交互结果块**按设计正常工作，并尝试可用按钮／链接。不能把这个假设扩展为落地页购物车、视频、下载或计算器均已经验证可用。

只在用户所需时访问相关页面，不为 block-only 路由把外部答案算入结果。反之，普通网页结果不能因抓取困难而回退成只看摘要。对图片、视频、声音或功能，正文文本未必包含主要价值，按实际需要查看／使用；无法观察影响结论的部分时记录证据不足。

## 2. 从抓取正文到可评价证据

可复用 url-body-fetcher 或等效读取工具取得的正文、原响应和页面文件，但先核对 URL、跳转、标题、内容身份、时间、截断和覆盖范围。确认不是 CAPTCHA、登录提示、服务商错误、搜索摘要或模型生成概述。使用历史材料需保留其时点；当前补查不能伪装成历史观察。

- 普通信息文章：阅读足够的实际内容，检查是否回答所需事实／条件，必要时核查准确性及来源。纯文本足以解释内容匹配的部分；布局／广告／媒体决定满意度时仍须补看。
- 功能／购物／媒体：检查与需求有关的功能、选项、画面或音频。不能因为正文短就低分，或因为文字看起来完整就假设用户能完成任务。
- 明确导航：核实确为目标网站／页面及实际可达状态；相似域名、品牌自称或标题不足以证明身份。安全停止不要求绕过恶意警告。
- YMYL、可疑事实、欺骗或垃圾内容：补查关键事实、相关责任主体、独立声誉和其他必要证据；不能仅因官网或熟悉品牌就免查可疑信息。

任务本身加载失败、读到乱码／不完整结果、代理被阻止，与用户目标页面真实无内容不同。合理补查后仍缺关键证据则标明不足，不强行 0 分。不要利用 URL 中的词推断未读正文，也不要将 snippet 当原文。

## 3. Needs Met 与 PQ

Needs Met 同时取决于 query 和结果；PQ 只评价落地页实现自身目的的质量，不取决于 query。没有要求 PQ 时不必额外输出独立 PQ 分数；需要 PQ 时读取并使用 page-quality-rater 的完整规则，以 `combined_nm` 语境评价实际落地页，SCRB 的块质量不能代替落地页 PQ。

毫无用处的结果无论 PQ 多高都 FailsM。不可信、过时、错误或有其他妨碍帮助性的特征，不适合 HM。乱码、诈骗等极低 PQ 可以让页面无用／有害而 FailsM；**明确网站意图且确为目标网站**是 FullyM 例外，不能把例外用于一般信息查询，也不能据此提高 PQ。真正未加载仍使用相应规则。

新鲜度、距离、语言、查询相关性不是 PQ 与 NM 的固定分数换算。输出两者时分别说明依据，不相加、不平均，不把“未评 PQ”变成“低 PQ”。

## 4. 信任、伤害与垃圾内容的检查

YMYL 是可能显著影响健康（包括心理／情绪）、安全（包括在线安全）、财务稳定、政府／公民事务与社会福祉的主题。既可能主题本身危险，也可能轻微错误导致严重伤害；受影响者不只读者，也包括其他人和群体。风险是连续的，不把所有新闻／健康／商品话题一律视为高风险。

可信需要准确、诚实、安全、可靠。合适的一手经验、专业知识、主题权威可支持信任，但不能抵消不可信。医学／财务等专业建议需相应能力，生活体验可以提供真实帮助但不能掺入有害错误。声誉须与主题、真正责任主体匹配；宿主名气、外观、流量数字或自称专家不是保证。小网站或普通人没有可查声誉不自动低分。客户评价要读内容与可信度，不把少数普通差评当恶意声誉。

以下条件成立时，按主规范的 FailsM 规则及导航例外处理；不能把关键词出现当作条件成立：

1. **伤害自己或他人：** 鼓励、描绘、煽动或直接造成身体、精神、情绪、财务伤害；严重威胁、恶意曝光隐私、便于模仿的暴力指导、赞美／淡化暴行、促成虐待、自伤／厌食、危险行为风险淡化、可能致严重伤害或妨碍救命治疗的反共识建议。极端暴力血腥或严重创伤性内容没有有益／教育目的也适用。对易受影响者存在合理伤害风险即可，不要求伤害所有人。
2. **伤害指定群体：** 宣扬、认可或煽动仇恨、暴力、虐待，恶意不容忍、优劣论或极冒犯／去人化刻板印象。群体特征包括年龄、种姓、残障、族裔、性别认同与表达、移民身份、国籍、种族、宗教、生理／社会性别、性取向、退伍军人、重大暴力受害者及亲属，以及其他系统性歧视／边缘化群体。须看严肃或恶意语境；批评思想／教义不等于仇恨人群。
3. **有害误导：** 可用广泛接受事实反驳的有害错误；与已确立专家共识相反的有害说法；没有合理事实依据、被充分驳斥或荒谬到不可信的有害理论，特别是削弱公共机构信任。故意与真心相信错误都可能成立，官方／专家不豁免。核查关键主张；未被事实核查网站记录不证明正确，普通主张暂时未验证也不自动有害。
4. **高度不可信／欺骗：** 多处或重大错误、必要责任信息完全缺失、极不专业的高信任指导、可信的极恶劣声誉；诈骗、仿冒身份／资质／店址、虚假亲测／独立评测、伪装新闻宣传、伪装广告／目录／按钮、故意遮挡 MC、诱导恶意下载或无理由索取敏感信息。强证据支持恶意怀疑即可停止，不必亲身受害。轻微夸张与故意欺骗要区分，免责声明不抹除已成立问题。
5. **垃圾内容：** 故意无 MC、无意义或极差 MC、入侵／篡改／大量垃圾评论、无价值关键词堆砌或伪搜索广告；过期域名被购买改作主要利于所有者而几乎无用户价值的内容；第三方主要借宿主既有排名信号发布内容的站点声誉滥用；大量生成主要利于所有者而不帮助用户的规模化内容滥用。后两者须有相应目的／模式证据，不从单篇风格、第三方或 AI 使用本身推断。
6. **近零增值复用：** 全部或几乎全部 MC 复制、改写、嵌入、自动／AI 生成或转载，且几乎无投入、原创和新增价值；署名不免责。低但不为零的编辑／整理价值须按实际帮助判断，不能一律当同一最低质量情形。必要时查辨识句段、标题、相似页面与历史版本，动态源当前找不到逐字匹配不证明原创。

**必要例外：** 有益的新闻、教育、历史记录、倡议、学术研究、艺术／讽刺、虚构娱乐不因讨论有害主题而自动有害；明确风险并劝阻模仿的危险表演不同于鼓励模仿。无害非 YMYL 娱乐、主观偏好、合理可争论问题、无关紧要小错误，不自动算有害误导。意见鲜明或令人不喜欢也不够。

正常广告、易关闭插页、可信付费墙、隐私登录、地域限制不自动不可信。合法授权／新闻联供、有价值专家解释、充分策展／讨论／功能投入不等于零增值复制。通讯社／新闻稿、合法联供、UGC、编辑作品、面向既有读者的原生广告、适当联盟链接／广告、商家直供优惠券，不仅因第三方存在就算站点声誉滥用。大量有价值内容或使用 AI 不自动属于规模化滥用。

如需正式 PQ，以上检查不能代替 PQ 五档定义及其完整程序；使用 PQ skill。NM 本身仍需足够的信任与帮助性证据。
