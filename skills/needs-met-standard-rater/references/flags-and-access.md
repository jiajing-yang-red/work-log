# 内容标记、语言与访问状态

标记描述结果本身，不依赖 query；Needs Met 分数仍依赖 query。记录 `true`、`false` 或 `null`（未知／未观察），不能把未查当作 false。部分任务还要求 Upsetting-Offensive 或 Not-for-Everyone，只有需要时添加。

## 1. Porn 与三种查询意图

Porn 标记用于结果块或落地页中的色情图像、文字、链接、弹窗或显著色情广告；按地区文化语境理解。不能仅因医学／人体／性教育话题就判色情。无论查询是否寻找色情，符合条件都应标记。

| 查询 | 评分规则 |
|---|---|
| 明确非色情意图 | 色情 MC 落地页 FailsM；不请自来的色情对许多用户是糟糕体验。girls、wives、mature women、gay people、people kissing、moms and sons、cheerleaders 等不能仅因可性化就改为色情意图。 |
| 可能色情也可能非色情 | 按非色情解释为主导评价，即使有些或许多用户可能寻找色情。breast／sex 等须先考虑健康、解剖等解释，色情结果在该语境 FailsM。 |
| 非常明确色情意图 | 按实际查询匹配、帮助性与体验评分，仍标 Porn；不是所有色情页都自动 MM／HM。错类型、错目标、恶意下载等应低分。清楚指定色情网站并确为目标时可 FullyM。 |

若发现疑似未成年人性剥削图像，不为评分继续打开、下载、复制或展示相关材料，停止互动并记录待人工处理状态。包括真实或合成、变形／组合、无法与真实区分以及符合相关情形的非摄影描绘；普通非性化儿童裸体本身不等同于性剥削。不能靠模糊外观做确定年龄／法律结论。平台有已授权举报流程时按流程处理，仅提供 URL，不传播图像；没有授权时指出需要人工按所属组织规则处理，不自行向外发送。此处是安全处置，不新增评分档位。

## 2. Foreign Language 标记

以**落地页语言**为准，不以搜索块外观、查询拼写或评分者个人能力为准。以下任一种不标 Foreign Language：

- 任务语言；
- 任务地区相当比例人口常用的语言；
- 英语。

其余语言即使是查询期待的，也仍需标 Foreign Language；即使评分者本人会读，也不能代表本地多数用户会读。多语言、无文字等难以判断时，从地区用户体验判断，拿不准不设置为 true。语言材料缺失则 null，不伪称已观察。

**对评分的影响：** 真正被标为 Foreign Language 的页面，多数情况下因当地用户无法理解而 FailsM。但查询明确期待该语言的目标网站、歌曲、电影、赛事视频等，可以有帮助甚至 FullyM。例如英语地区明确查 baidu.com，正确中文主页可以 FullyM + Foreign Language。歌曲／电影的外语视频可能可欣赏，而用外语谈论该歌曲的视频对听不懂的人可能 FailsM。视频语言与页面语言也可能不同：英文界面上的法语演唱不因演唱语言就自动给页面外语标记。

**英语的特别规则：** 英语不标 Foreign Language，不表示它对所有地区都能得高分。非英语地区通常期待任务语言；多数人不能读的英语结果，除非查询确实需要，否则可无用而 FailsM。拉丁字母拼写、英语品牌／人名或几个英文词不等于要求英文页面；可能只是转写。国际机构官网、技术型号／公式／命令等在某些地区可能期待英语，需结合当地惯例。若无法确定，优先假设用户希望任务语言。

## 3. Did Not Load 标记

仅基于实际落地页确认以下情况时使用：

- 页面完全空白，无 MC、SC、广告；或
- 只有通用服务器／应用错误，没有导航、首页链接、SC、广告等其他站点内容。

真正未加载的落地页无用，标 Did Not Load，并依规则评 FailsM。不能仅凭 HTTP 404、服务商的“not found”、超时、robots／反爬、验证码、提取失败或摘要判断。需区分抓取器无法访问与普通用户实际见到的页面；无法分辨时补查，仍不明用 insufficient_evidence。

以下不标 Did Not Load：

- 恶意软件警告：可据明确警告认定恶意，不继续访问；普通查票等查询应 FailsM，若评 PQ 则 Lowest。
- 删除帖子、过期分类信息、已下架商品／不可用服务：按实际内容与查询帮助性判断。
- 订阅／登录后才能看到 MC：不是无内容或技术加载失败，不编造隐藏内容。
- 有网站内容、导航或帮助的定制错误页／部分加载页：按实际帮助评分。例如查 Bible passages 的错误页仍有所有经文目录，可以很有帮助；无所需鞋款信息的商品错误页可 FailsM。

证书、安全过滤或网络警告不是自动的恶意证据；不确定且不能安全继续时用 unable_to_assess。任务结果块自身没加载是任务材料故障，先合理刷新／补查，仍缺失则记录无法评价；不因此断言落地页 Did Not Load。没有落地页或按块本身评价的 SCRB，不因“未提供网页正文”而标 Did Not Load。

## 4. 其他标记与 PQ 分流

Upsetting-Offensive：从任务地区典型用户视角，可能令人不安或冒犯；考虑人群多样性，不以个人政治／宗教偏好判断。

Not-for-Everyone：可能使当地一些人不舒服、不宜在公共场所、职场或学校展示的内容。两者都不是自动的 FailsM／Lowest，仍按实际意图、伤害及质量规则。

标准 NM 必须继续评价有 Porn、Foreign Language、Did Not Load 标记的结果，不能直接套用独立 PQ 的提前退出。联合任务中无法评价外语或未加载页面的 PQ 时，可将 PQ 留空并解释；NM 仍按上述规则处理。其他 PQ 前置条件按任务语境与 PQ skill 执行，不把缺证据记作低质量。
