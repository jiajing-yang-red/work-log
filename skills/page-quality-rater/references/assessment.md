# 页面调查与质量维度

本文件是所有正式 PQ 任务的必读标准。内容依次为：真实目的与责任主体、MC/SC/Ads、YMYL、MC 质量、独立声誉、E-E-A-T、访问与调查边界。

## A. 真实目的、网站及责任主体

1. 先看实际落地页，再寻找与该页面最相关的首页和独立站点部分。网站可能有目的不同、相对独立的子站；多个首页候选时选择最能解释目标页的，不必寻找唯一“正确首页”。缺少首页链接本身不证明低质量。
2. 网站所有者是对站点负责的人或机构；主要内容创作者可能不同：
   - 公司首页、个人介绍页、商家商品页，通常由网站／商家对 MC 负责，即使聘人开发或含用户评价。
   - 报刊文章、学术论文等，网站承担发布责任，署名作者、团队或编辑组织是主要创作者。
   - 社交账号帖子、商家社交主页、视频频道，发帖个人或组织是创作者，宿主平台不是每篇内容的创作者。
   - 多人论坛／问答／社交内容汇总，参与发帖的人共同形成 MC，可能没有单一主要创作者。
3. 查 About、作者简介、编辑／审核信息、Contact、客服等。不能只信“我是专家”或官网自夸；自述与可靠独立证据冲突时，更相信独立证据。
4. 需要的责任与联系信息取决于目的、主题、网站类型及当地惯例。商店、银行、支付、密码／敏感数据处理站点要求更高；商店检查付款、换货和退货政策及求助渠道。合理个人匿名、长期用户名或别名可接受；不普遍要求公开真实姓名、住址或电话。非 YMYL 的个人网站或论坛讨论，仅电子邮箱或社交链接也可能足够；这不是交易网站客服充分性的通用标准。官网社交账号可提供联系信息，但不是独立声誉来源。
5. 页面可能有一个或多个目的，先识别实际目的再评价实现程度。分享个人经历、观点、感情、媒体，展示才能，幽默和艺术，销售商品服务，发问交流，提供软件／文件，支持公益，均可能有益。看似奇怪的页面要先理解其创作目的。盈利与帮助用户可以共存；仅为所有者利益而几乎不帮助用户才触发对应最低档。

## B. 区分 MC、SC 与 Ads

| 部分 | 判断方式 |
|---|---|
| MC（Main Content，主内容） | 直接帮助页面实现目的的任何部分，包括正文、页面顶部标题、图像、音视频、计算器、游戏、购物或登录功能、评论和其他用户创作。折叠标签里的商品评价、配送、安全信息也可能是 MC。 |
| SC（Supplementary Content，补充内容） | 有助于用户体验，但不直接完成页面核心目的，例如导航。内容是否 SC 取决于其作用；不能把所有评论或标签内容固定归类。 |
| Ads（广告／变现内容） | 为变现而展示的内容或链接，包括广告、赞助和各类变现／联盟链接。是否标为 Ads 不是唯一识别方法；也不能把正常商品页销售的产品信息一律当成广告而忽略其 MC。 |

网站可能不直接选择每条广告，但仍对总体广告体验负责。广告因刷新、设备、用户而变化，移动端变现可能更隐蔽。广告的有无、数量本身不是自动加减分规则，重点是欺骗、干扰、遮挡和内容是否不当。应观察未被人为广告过滤改变的体验；若现用工具过滤了广告或只返回纯文本，不得据此声称“没有广告／没有干扰”，记录证据限制，必要时补充实际页面画面。不要为了评分擅改用户扩展、安全设置或访问权限。

干扰也可能来自广告／SC 的内容，而非只来自数量或位置，例如非性主题页面上的性暗示图像、怪诞图像、耸动或令人困扰的标题与画面。评估它们是否显著打断 MC 使用；实际色情内容另外按前置任务标记处理。不要以“正文不错”忽略明显干扰，也不要把审美不合自动当作干扰。

## C. YMYL 的判定

YMYL 是可能显著影响健康、财务稳定、安全，或社会福祉的主题。影响可落在直接读者、受其行为影响的其他人、群体或整个社会。

| 风险类型 | 范围 |
|---|---|
| 健康与安全 | 身体、心理、情绪健康，身体及网络安全；自伤、犯罪和暴力极端主义等本身危险的主题。 |
| 财务安全 | 可能损害个人及家庭维持生计能力的决定或信息。 |
| 政府、公民与社会 | 影响人们生活的公共事务、选举与投票、公共机构信任，以及可能影响群体和公共利益的议题。 |
| 其他社会福祉 | 其他可能显著伤害个人或社会福祉的主题。 |

主题本身危险，或不准确、不可信内容可能造成显著伤害，都可构成 YMYL。不能因为“任何网站都可能有恶意下载”把所有主题都列为 YMYL；也不能把所有健康、新闻或商品话题一概视为同等高风险。

风险是连续的，可记录 `clear`、`possible`、`unlikely` 作为本地描述。思考：谨慎的人是否需要专家／高度可信来源以避免伤害？轻微错误是否可能严重影响人？如果只是多数人可以随意咨询朋友的小问题，通常较低风险。

典型区别：海啸疏散路线和何时急诊属明确高风险；日常天气、更换牙刷频率视情境可能低风险；音乐奖项和洗牛仔裤通常非 YMYL。重大持续暴力新闻可能关乎安全及社会决策，而一则普通体育报道不因此成为 YMYL。处方药购买的信任要求远高于买铅笔；普通汽车评测不能只因售价高就直接等同于最高风险。

对明确 YMYL 严格检查准确性、适当专业知识、共识、责任信息和信任。经验分享与专业指导不同：安全的孕期睡姿经验、面对治疗的心理经历、纳税挫折的幽默视频、服务使用体验、首次投票感受，可以有价值；用药、疗法及预后、填税表、投资配置、投票资格／登记则需要相应专业／权威信息。生活经验不能掩盖混入其中的有害错误。

## D. MC 质量：衡量目的实现，而非篇幅

统一问题是：MC 在多大程度上让页面实现目的，并提供令人满意的体验。按内容类型考察以下因素，不把它们做成加分项计数：

- **投入（effort）：** 人对创作、编辑、筛选、设计、实作和功能系统的投入。人工翻译诗歌与开发有价值的翻译工具都可有投入；无监督地批量翻译现成网页并不自动体现投入。多人讨论的参与和深度可累积成显著人类投入。
- **原创性（originality）：** 原创信息、独特经验、图像／视频、观点或功能，及是否为同类内容的最初来源。合理整理、解释、编辑和新增背景也可能有用户价值；纯搬运与有价值改写需区分。
- **才华／技能（talent / skill）：** 是否足以使该种内容达到其目的。手工或维修教程需要正确清楚的实作能力，艺术或娱乐需要适合其分享目的的才能；普通人记录初学尝试不能按专业电影标准要求。
- **准确性与共识：** 信息页面须考虑事实准确，YMYL 尤其要符合已确立的相关专家共识。高质量信息须准确；非常高质量信息还应清楚充分。必要时核查决定性的事实、来源和专业共识，而不是因为“文风专业”就信任。

充分阅读文章、观看相关视频、检查图片、使用适当工具功能，再结论。与页面目的有关的隐藏标签、评论、讨论及功能也应纳入。有疑问时比较同主题的其他页面校准标准，但不是将当前候选集的最好一条强制判 Highest。

实测采用已授权、安全且与目的有关的操作；例如无个人数据的计算器测试或可逆的购物车检查。不以评分为由执行购买、提交敏感信息或下载运行未知软件；未能测试的关键功能如实注明，不能写成“可用”或“不可用”。

短视频、长篇报道、图片、音频、工具、论坛都可能优质。功能完善不等于必须文章很长；长文不等于投入大。最有帮助、最关键的 MC 应突出且接近页面顶部；支持目的但不直接完成核心目标的内容，可放在较靠下、不太突出的地方。

filler 是低投入、占据有价值的突出位置，却不提供价值或无助于令人满意地实现主要目的的内容。以下任一情形可支持 Low：大量低质量、无帮助的 filler 造成糟糕体验；大量视觉上突出的 filler 让有帮助的 MC 难以找到、令人受挫。不能把第二种情形当作第一种的必备条件。位置恰当、确有支持价值的背景信息不属于 filler。

时效按页面目的解释：当前指导是否已过时，历史档案是否准确反映当时，不能仅凭发布日期久远或缺少日期设统一档位上限。已经失效到影响目的或信任的内容应据实降低质量。

## E. 独立声誉调查

**对正常可继续的 PQ 任务，声誉调查是必做步骤。** 不能只看页面上的自述、设计或认证图标。危险页面应按最低档规则停止互动，前置退出任务也不必继续无意义调查。

1. 确定站点、背后真实机构／企业和主要创作者；如果作品分布于多个网站，调查实际创作者，不局限于一个域名。
2. 使用站点／机构名、域名、创作者姓名及主题关键词，必要时结合 `reviews`、`reputation`、`-site:目标域名` 等查找外部资料。搜索词只是方法示例，不要求固定搜索引擎或调用次数。
3. 阅读可信独立评价、专家推荐、专业团体、新闻报道、百科及其引用、消费者记录、相关论坛讨论等。机构自己维护的社交账号、公关转载或宣传声明不自动成为独立证据。若来源本身注明内容存在争议或可能过时，应进一步核查，而非直接据其形成确定的声誉结论。
4. 声誉必须匹配当前主题：擅长幽默不代表可信金融专家。YMYL 主要看有相关专业能力的来源；新闻可看新闻奖项和原创调查记录；专业作者可看学历资格、同行认可、专家合作者、引用和相关任职；非职业作者可从实际内容、评论和同领域参与者评价获得较非正式证据。
5. 客户评价要读具体内容，结合数量、可信度和范围。正负评价都可能伪造；大量详细可信好评可支持良好声誉。单次店员无礼、一个包裹延误或少数差评，不能推出整体负面声誉。多来源可信诈骗、收款不发货、犯罪或威胁记录则可支持极负面声誉。
6. 网站访问量、流量排名和自动汇总统计不是正负声誉证据。非 YMYL 的真实知名度、参与度和用户评价可以作为主题声誉证据，但不把“浏览量很高”直接当作声誉结论。
7. 大网站、知名或职业创作者通常应有可查背景；小商家、社区、业余作者与匿名个人可能没有。**查不到声誉既不是正面也不是负面，仍可能 High / Highest。** 转而重视 MC 和适当 E-E-A-T，YMYL 更谨慎。
8. 记录查了什么、找到或没找到什么，以及来源是否独立。不把“未开展调查”“工具不可用”和“调查后未发现信息”混写成同一结论。

## F. E-E-A-T：Trust 为核心

| 概念 | 实际判断 |
|---|---|
| Experience：经验 | 创作者是否具有该目的需要的一手使用、实践或生活经历。 |
| Expertise：专业知识／技能 | 创作者是否有该主题需要的知识或能力，可正式也可非正式；不局限于证书。 |
| Authoritativeness：权威性 | 在此主题是否为公认可靠、常被优先参考的来源；可能是官方独特来源，也可能是地方机构、经验社区或特定创作者。大多数主题不只有一个权威。 |
| Trust：信任 | 页面是否准确、诚实、安全、可靠；E、E、A 可支持它，但不能补偿不可信。 |

不同主题需要的组合不同，经验与专业知识可能重叠，不必勉强把每条证据拆开计分。E-E-A-T 的依据可来自以下一类或多类：自述及可核查背景、独立来源评价、MC／演示／评论及实际功能体现的能力。不要求三类都有正面证据；实际内容本身可以清楚展示经验或专业知识，但正常 PQ 任务仍须开展声誉调查。不可仅凭自称专家、昂贵设计、宿主品牌或 HTTPS 就判可信。

商家需要安全支付与可靠客服；评测需要诚实地帮助购买决策；YMYL 信息需要准确以防伤害；无害娱乐不必被要求与医疗指导同样的专业可信度。产品厂商自评或付费推广存在利益冲突，不能当成独立体验评测；但厂商对自家产品规格仍可能权威，应按页面目的判断。清楚披露利益关系本身不自动使页面高质量，也不自动使页面最低质量。

Trust 不完全被其余三项覆盖。无论创作者看起来多有经验、多专业、多权威，只要页面不可信，E-E-A-T 就低。替代疗法、冷门爱好也有不同水平的经验／专业知识，但有害、严重误导、不可信或垃圾内容仍优先 Lowest。

其他信任证据也要考虑，例如商店的客服信息、学术作者的同行评审发表记录，而不只检查姓名和资质。

## G. 调查结束与证据限制

调查应足够支撑决定性判断，不无限浏览。没有足够事实确认的嫌疑要明确为嫌疑；符合强烈恶意怀疑的特定规则时可判 Lowest，其他关键缺口无法解决则使用 `insufficient_evidence`。

纯文本提取看不到广告、布局或视频时不能声称已经检查这些部分；必要时查看实际页面或用户提供的截图／视频材料。工具抓取错误、地区封锁、登录限制与页面客观坏掉不是一回事。缺失证据是否妨碍最终分档，应根据它对当前决定的影响判断，不给所有受限观察套统一分数上限。
