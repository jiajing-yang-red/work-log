# 前置分流与特殊页面

## A. 前置分流：不评分不等于最低分

使用独立 PQ 任务的前置规则。以下状态不填写整体 PQ，输出 `not_rated`，`rating=null`、`score=null` 并说明原因：

| 情况 | 判定与限制 |
|---|---|
| Porn | 实际页面的色情内容，包括色情图像、文字、链接、弹窗或显著色情广告；依据任务地区文化语境判断，不依赖 query 是否寻找色情。不要仅因话题涉及性或人体就忽略其实际语境。 |
| Foreign Language | 页面语言不属于任务语言、任务地区相当比例人口常用的语言，也不是英语。不能把“非中文”一律当外语；英语不使用该退出标记。缺任务地区且它会影响判断时说明缺口，不猜国家。 |
| Did Not Load | 确实看不到任何网站提供的内容：没有 MC、SC 或 Ads；例如完全空白，或只有通用服务器／应用错误且没有导航、首页链接等其他内容。必须基于实际访问，不能只看搜索摘要、HTTP 状态或提取器报错判断。 |
| Restricted / Inaccessible MC | 需要订阅、权限或登录才能看到实际待评 MC，且当前不能访问。不能凭网站名气补齐隐藏内容，也不能因正规付费墙或隐私保护判低质量。 |

纯工具失败、抓取被阻止或缺少实际页面材料且无法分辨站点状态时，用 `insufficient_evidence`，而不是断言网站 Did Not Load 或 Lowest。已观察到明确恶意软件警告或足够强的恶意证据时按 Lowest 的安全停止规则，不要误归普通加载失败。

上述提前结束规则适用于独立 PQ 任务，不把另一个任务要求“所有结果必须有 Needs Met 分数”的规则搬进来。其他内容标记如令人不安／不适合所有场合，只有任务要求时记录；它们不自动等于 Lowest，须看实际伤害标准。

### 联合 Needs Met 任务中的 PQ

记录 `task_context: combined_nm`，仍用同一套页面目的、MC、声誉和 E-E-A-T 标准，但遵循联合任务的评价范围：

- 任务要求 PQ 时，以实际落地页为依据，包括特殊结果块关联的落地页；不要求 PQ 时不必额外输出。块内信息不能代替该页面的质量证据。
- Porn、Foreign Language 和 Did Not Load 是结果标记，不能仅因设置了标记就取消该结果的 Needs Met 评分。它们也不是 PQ 档位。
- 对 Foreign Language 或 Did Not Load 结果，若无法评价 PQ，可以保留 N/A（本地输出为 not_rated、rating/score 为 null），说明原因；不是把独立任务的所有提前退出机械复制过来。英语以及当地相当比例人口常用语言，不标 Foreign Language，但评分者仍须具备实际理解能力。
- Porn 标记不代表该内容自动为 Lowest，也不能自动触发联合任务的 PQ 退出；按照项目要求、实际可安全观察的证据及质量标准判断。遇到违法／危险内容不为完成评分继续访问，按安全处置并记录限制。
- 受限内容无法观察时，不编造隐藏 MC 的质量；根据项目要求与实际缺口记录未评分。明确登录入口本身仍可评价。
- 目标网站可能同时为 FullyM 和 Lowest：Needs Met 的明确导航例外只影响 NM，不影响 PQ。不能根据 query 是否喜欢／需要内容而改变 PQ。

Foreign Language 标记遇到多语言或无文字页面时应结合当地用户体验，无法确定不设为 true；未知材料不能写成已核实非外语。明确的恶意软件警告可支持 Lowest；普通证书／网络错误不能直接推出恶意。

## B. 百科

- 不能仅凭“百科”或知名站点判 High / Highest。作者不明时，重点调查网站的准确性和专业声誉，再检查条目自身 MC 与引用。
- High / Highest 的百科，应有很好的准确性和专业声誉，条目本身经过良好研究并附适当参考来源。
- 非 YMYL 条目有令人满意的准确内容和可信外部引用，通常可在 High 范围；内容和引用较有限、仍实现目的时通常 Medium；极少 MC 或事实错误要检查 Low / Lowest。
- 同一协作百科的条目质量有差异，宿主总体良好声誉不代表每篇内容有准确性保证。

## C. 错误页、移除内容与真正坏页

- 定制 404 或明确错误说明，本身可以为用户解释问题并提供帮助；不是“有 404 就低质量”。最基本但有帮助的错误页常 Medium；投入高、提供有效搜索和建议的可 High；极少数独创、非常令人满意且满足其他标准的可 Highest。
- 网站框架、导航等存在，但本应展示的 MC 因孤立临时故障而缺失、功能未能实现，通常 Low；并非一律按前置 Did Not Load 退出。
- 检查其他页面。若许多页面相同地缺失 MC，体现系统性缺乏投入、仅广告或故意空内容，可 Lowest。不能从一个页面坏了直接推断全站故障。
- 下架商品、过期分类信息、删除帖子不自动 Did Not Load。评价当前真正存在的页面目的、解释和帮助；若关键 MC 确实受权限限制，则按相应退出规则。
- 没有任何网站内容的通用错误／空白页，适用前置 Did Not Load，不强给质量分。

## D. 论坛与问答

- MC 包括提问、回答、回复和讨论。从访问页面的读者角度评价，不站在某位参与者的立场。
- 用户名或别名足以标识个人贡献者，仍可 High / Highest。经验和专业能力常能从具体帖子及他人反馈看出；YMYL 更重视适当信任和准确性。
- High / Highest 可来自深入、有洞见、参与者付出显著努力且有相关经验／专业知识的讨论；丰富独特生活经验尤其有价值。非专家可信经历可以 Highest，不把其误作临床建议。
- Low 可能源于少量／表面讨论、经验或专业知识不足、轻度错误、显著不尊重或缺乏礼貌以致妨碍正常交流。
- 有害误导、危险医疗建议、违背已确立共识或鼓励伤害，应 Lowest，不能以“只是某个用户的意见”免责。
- **新发布**的真实问题或讨论，只有初始帖且尚无人回复，通常 Medium，除非有其他低质量特征；不能假定所有未回答问题都“刚发布”。
- 长时间无实质回复、只有无帮助回答或表面讨论，可支持 Low，尤其还伴随其他问题。不能设统一的小时或天数阈值。
- 讨论偏题、争执或混入低质内容时，仍衡量其中真实有价值的讨论。若有 High 与 Low 混合但仍有见解、没有潜在伤害，Medium 可能最恰当；严重垃圾污染或有害内容仍服从最低档规则。

## E. 商店、登录页、功能页、音视频与非 HTML 文件

- 商店：商品信息、选项、评价、配送／安全标签和必要购物功能可都是 MC；同时检查责任、客服、付款换退政策、交易信任。漂亮商品图、低价格、HTTPS 或“官方”字样不是可信度证明。
- 银行等登录页：若 URL 的实际目的就是提供登录入口，清楚可见的入口和身份信息可被评价，不需要读取他人账户或真的输入密码。**登录页本身可评**与**登录后隐藏的账户／正文不能评**必须区别。
- 计算器、游戏等：核心价值可能是功能，不以文字少为由低分。能安全测试时实测；无法测试则说明局限，不伪称验证成功。
- 视频、音频、图片：实际观看／收听／查看与目的有关的内容；只见标题或字幕不能替代所有视觉、音频或技能表现。若证据足够支持决定性判断，可注明范围；否则补查或弃权。
- PDF、PNG、JPEG 等：根据其实际目的使用适用标准；普通网页的导航、SC、联系方式等有些要求不适用。例如官方校园地图可凭地图质量及相关权威性达到 Highest，不因文件没有网站导航而扣分。
- 正规登录、订阅或地域限制本身不低质；原本受限的 MC 仍按前置规则处理，不能因为所属平台知名就把缺失内容评为 High。
