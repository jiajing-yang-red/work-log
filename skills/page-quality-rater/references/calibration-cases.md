# 规则边界案例

以下是条件完整时的校准要点，描述案例当时已给出的页面证据，不是对当前在线网站的评价，也不是已执行的模型准确率测试。列出的档位依赖整组证据；不能拿某个词或单一表面特征套档。

| 情境 | 应用与边界 |
|---|---|
| 无害爱好页有深入原创实作，小站点没有外部声誉 | 无声誉不自动降档；充分 MC 和经验可支持 High，极突出时可到 Highest，仍需完成调查。 |
| 未知网站页面排版精美，可信多来源记录其收款不发货且威胁顾客 | 极负面／恶意声誉使整个网站不可信，其所有页面应 Lowest；美观不能补偿。 |
| YMYL 个人经历准确、安全、尊重他人；讨论深入且经验丰富 | 可 High / Highest；不能机械要求每位参与者都是执业专家。 |
| 同一经验帖混入可能使读者错过投票的错误日期 | 有害误导 Lowest，原本有价值的生活经历不能抵消。 |
| 健康指导内容与医学共识冲突、作者极不专业且不可追责 | Lowest；不只是因为“非官方”或“没有作者简介”单一表面因素。 |
| 知名网站文章浅薄，缺少该专业建议必需的 E-E-A-T | Low；品牌和好声誉不能补偿必要专业信任缺失。 |
| 新闻表达明确立场，但事实准确，没有其他有害误导或欺骗 | 不因立场不合个人偏好而低分，按质量正常评价。 |
| 有益历史纪录片引用仇恨言论以记录和解释历史 | 不能把所记录的言论自动当作影片在宣扬仇恨。 |
| 非讽刺页面伪造专业资格，宣称未做过的独立亲测 | 欺骗成立时 Lowest，不当作一般广告或轻度夸大。 |
| 作者自我介绍夸大经验，但尚不构成故意／显著身份欺骗 | 按轻度误导检查 Low；注意继续核查是否达到 Lowest。 |
| 原创内容含正常广告，或只有一个容易关闭的弹窗 | 不因此降档；检查实际干扰程度及其他质量。 |
| 页面有用但干扰性广告显著打断阅读 | 通常 Low；有价值讨论与高 E-E-A-T 等补偿性优点充分时，混合质量可 Medium。“一个 Low 特征”不限定为轻度，不能机械平均或据此忽略伤害。 |
| 广告持续遮挡且关闭按钮诱导下载；MC 几乎无法找到 | 故意操控／欺骗，Lowest。 |
| 正规新闻付费墙只显示标题和几句引导 | 受限 MC，not_rated；不凭品牌给正文 High，也不因付费判 Lowest。 |
| 正规银行登录入口本身清楚、可信，相关权威和声誉充分 | 登录页本身可 High / Highest；无需进入账户来评价入口。 |
| 全空白或纯通用服务器错误，无网站其他内容 | Did Not Load，not_rated。 |
| 新闻页导航正常，正文因孤立临时故障缺失 | 通常 Low；不是有任意加载问题都退出。 |
| 全站大量模板页只有广告，没有 MC | 系统性缺乏有益内容，Lowest。 |
| 定制 404 清楚解释问题，提供首页等基本帮助 | 常 Medium；若搜索建议、独创内容和体验极出色，可能 High / Highest。 |
| 新发的真实论坛问题，只有初始帖，尚无回复 | 无其他低质量特征时通常 Medium；不能套用长期未回答的 Low 理由。 |
| 很久无人参与、唯一回答毫无帮助且页面干扰严重 | Low；若有有害误导或严重垃圾污染再检查 Lowest。 |
| 非专家详细分享亲友癌症经历，目的在经验与支持 | 可以 Highest；若变成错误医疗指导则重新应用更高信任和伤害标准。 |
| 百科主题很窄，短文和引用足够完成目的，但无突出特点 | Medium；不是所有百科都 High，也不是短文必 Low。 |
| 经过充分研究、准确且适当引用的百科，站点有很好相关声誉 | 可 High / Highest，需看该条目实际质量。 |
| 合法联供报道，或专家把复杂政策准确解释成易懂文字 | 不因复用而自动低分；看实际增值、可信度和目的实现。 |
| 大量摘录别人的评测，只有很少人工整理或原创补充 | 通常检查 Low；近乎全量零投入、零原创、零增值则 Lowest。 |
| AI 辅助制作的原创艺术作品，投入和表现充分 | AI 标签不决定 PQ；按作品目的、才能、原创性等评价。 |
| 多页核实发现批量无增值内容，不知道使用了哪种生成工具 | 可 Lowest；不必证明用了 AI。 |
| 学校旧域名被买来发布无关低价值赌博推广，历史快照证实变更 | 过期域名滥用，Lowest；仅换域名所有者不等于成立。 |
| 新闻站正常刊登编辑专栏或合法联供 | 第三方创作本身不构成站点声誉滥用。 |
| 第三方推广页主要借宿主排名信号，并伪装独立评测 | 检查站点声誉滥用及欺骗，成立则 Lowest，披露赞助不自动免责。 |
| 高质量页面完全不回答当前 query | PQ 不降；这是另一个评价维度的问题。 |
| 任务语言是中文，页面是英语 | 英语不使用 Foreign Language 的 PQ 退出标记；仍需能实际理解并调查。 |
| 只提供搜索 title、snippet、URL，没有实际页面证据 | insufficient_evidence；不把摘要评分包装成 PQ。 |
| 工具提取失败、证书提示或访问限制，但不知用户实际看到什么 | 记录限制，不能自动判站点 Lowest 或 Did Not Load。 |
| 明确恶意软件警告 | 不继续访问，可按 Lowest；不是一般的 Did Not Load。 |
| 官方校园地图 PDF 没有网页导航 | 有些普通网页条件不适用；可凭地图 MC、准确性及相关权威性 Highest。 |
| 有帮助的核心内容能找到，但大量低质、无帮助的填充文字造成糟糕体验 | 已符合 filler 的一条 Low 条件，不必再证明核心 MC 难找；仍与混合质量及其他档位规则一起判断。 |
| 网站明确披露 AI 辅助、已知局限，并建议核实；目的与对外陈述一致 | 这些披露本身不构成目的欺骗；仍评估实际准确性、投入、信任和其他质量条件。 |
| 已有充分证据表明过期域名被购买，改作主要让新所有者获益且几乎无用户价值的内容 | 过期域名滥用，应 Lowest；不必额外取得排名收益数据、所有者自认或用户被骗的证明。 |
| 多页调查证实大量内容主要为所有者获益且不帮助用户，虽然做过少量人工编辑 | 人工编辑的存在不排除规模化内容滥用；按真实目的、规模和价值判断，成立则 Lowest。 |

核对案例时，尤其注意：正面条件的“至少一项”不等于可以忽略基础信任要求；单个 Low 特征的充分性与 Medium 混合质量例外必须一起读；所有 Lowest 规则的伤害、故意性、严重程度、规模及增值限定不可省略。
