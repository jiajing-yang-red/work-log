# 每日工作记录

按年月归档，每天一篇。同一天涉及多个项目时，写在同一篇里，用项目名称标出每条进展。

## 按月查看

| 年份 | 月份 |
| --- | --- |
| 2026 | [11 月](2026/11/) |

## 写一篇日报

1. 复制[日报模板](TEMPLATE.md)，保存为 `daily/YYYY/MM/YYYY-MM-DD.md`。当天已有文件时直接追加。
2. 标题用一句话概括当天最重要的进展。正文写清完成了什么、如何验证，并链接到对应的提交、报告或项目。需要继续处理的问题放在「待跟进」。
3. 每月第一篇发布时，在上表加入月份链接。阶段性成果也可以记入[仓库首页](../README.md#工作进展)。

## 自动发布

[工作日报工作流](https://github.com/jiajing-yang-red/work-log/actions/workflows/daily-report.yml) 在北京时间周一至周五 00:00 触发。周一汇总上周五，周二至周五汇总前一天。每篇按该日期的北京时间 00:00 到次日 00:00 统计 `main` 的提交，以 Git 提交者时间为准。

每次运行都会检查从 2026-11-18 起已到期的工作日，补齐缺少的日报和月份链接。汇总依据提交说明、文件差异及项目进展文档，保留手写内容，并用提交链接避免重复记录。当天无工作提交时记一行说明。需要立即补跑时，在工作流页面选择 **Run workflow** 并使用 `main` 分支。
