# 每日工作记录

按年月归档，每天一篇。同一天涉及多个项目时，写在同一篇里，用项目名称标出每条进展。

## 写一篇日报

1. 复制[日报模板](TEMPLATE.md)，保存为 `daily/YYYY/MM/YYYY-MM-DD.md`。当天已有文件时直接追加。
2. 标题用一句话概括当天最重要的进展。正文写清完成了什么、如何验证，并链接到对应的提交、报告或项目。需要继续处理的问题放在「待跟进」。
3. 每月第一篇发布时，在上表加入月份链接。阶段性成果也可以记入[仓库首页](../README.md#工作进展)。
